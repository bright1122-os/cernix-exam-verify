## 2. Login Authentication Application

### Description

The login application is a simple web-based authentication form. It validates the username and password entered by the user and displays either a success or error message.

### Demo Login Details

```text
Username: student
Password: 12345
```

### Features

- Username input field
- Password input field
- Submit/Login button
- Reset button
- Input validation
- Success message
- Error message
- Responsive user interface

### Technologies Used

- HTML
- CSS
- JavaScript

### How It Works

The login form checks if the username and password fields are empty. If both fields are filled, it compares the input with the demo login details. If the details are correct, it shows a success message. If not, it shows an error message.
